# Automations

Приватный репозиторий Марка Малиновского для конфигурации n8n, процессов интеграции сервисов и их проверок.

n8n дополняет Gate: соединяет API, Webhook, расписания и готовые интеграции. Канонические данные пользователей и бизнес-правила остаются в соответствующих прикладных сервисах. Telegram-трекинг — возможное дальнейшее использование, не уже подключённый процесс.

Первая задача: обычный ChatGPT Work → защищённый HTTPS n8n → GitHub, ~100 отдельных файлов / ~30 MB, сохранение путей и байтов, один commit/push, повтор запроса и restart. Текущий маршрут загрузки сохраняется до полной приёмки.
