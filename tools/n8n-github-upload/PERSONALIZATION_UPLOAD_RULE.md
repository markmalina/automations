# Подготовленный текст персонализации

Статус: DRAFT, в настройки аккаунта не установлен. Маршрут включается по умолчанию после полной приёмки и подключения текущего Work.

Команды «выгрузи», «сохрани» и «обнови в репозитории» выполняй через маршрут Work → n8n → GitHub после его полной приёмки и подключения текущего Work. Передавай файлы программно, сохраняя байты, имена и папки, одним коммитом на комплект. Проверяй результат в GitHub и возвращай ссылку на коммит. При потере ответа сначала выясняй исход операции; не создавай дубликат слепым повтором. Если n8n недоступен или текущий Work не подключён, прямо сообщай об этом и используй действующий GitHub-коннектор, когда он позволяет выполнить поручение. Инструкции и текущий статус: https://github.com/markmalina/automations/issues/1.

Официальная справка: https://learn.chatgpt.com/docs/personalize . Персональные инструкции добавляются в Settings → Personalization; файл в репозитории сам не меняет настройки аккаунта.
