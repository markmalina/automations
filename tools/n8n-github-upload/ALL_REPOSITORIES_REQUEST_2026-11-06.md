## GitHub: точный объём расширения

На странице https://github.com/settings/installations/179245428 выбрано **All repositories**, кнопка **Save НЕ нажата**. До сохранения действует прежний доступ только к freelance.

Подготовленный вариант даёт App доступ ко всем текущим и будущим repositories, принадлежащим личному аккаунту `markmalina`, включая приватные. Состав permissions остаётся тем же: metadata read и contents/code read/write. Это расширение круга репозиториев, а не необходимость создания нового ключа.

Поскольку это выдача приложению нового доступа к приватным данным и записи содержимого, перед Save требуется явное подтверждение именно расширенного scope. Формулировка для владельца: «Подтверждаю доступ GitHub App ко всем текущим и будущим репозиториям markmalina, включая приватные, с правом записи содержимого».

Наличие такого доступа не разрешает загрузчику самостоятельно выполнять массовые изменения: каждый комплект всё равно должен быть связан с явным поручением, repository/branch/destination и отдельным upload ID. В штатном процессе installation token желательно выпускать только для repository данного комплекта; полная реализация ещё впереди.
